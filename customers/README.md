# Customer Evidence

This directory stores real customer or user evidence that can influence OS decisions: interviews, support notes, objections, observed behaviour, supplied analytics, and explicit feedback.

## Evidence Rules

- Record where and when the evidence came from.
- Distinguish direct statements, factual summaries, and interpretation.
- Use short compliant excerpts; do not copy entire copyrighted sources.
- Remove secrets and unnecessary personal information.
- Do not invent quotes, customers, statistics, behaviour, or results.
- Do not place product assumptions here unless clearly labelled as hypotheses.
- Obtain approval before adding sensitive, private, or externally sourced customer data.
- Update existing notes instead of duplicating the same evidence.

## Naming

Use `YYYY-MM-DD-source-topic.md` with a concise, sanitised topic.

## Usage

Tickets should link the relevant note and state how it affects scope or acceptance criteria. Customer evidence can inform a recommendation but does not automatically authorise product or implementation decisions.
